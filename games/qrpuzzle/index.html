How the playground works

Pick a language in the tabs above. qr.current is the broken QR as an (n, n, 3) array of RGB values 0–255 (in JavaScript a nested array of [r,g,b]; in Python a NumPy array; in Lua a 1-indexed table of {r,g,b}). Black/white levels are just (0,0,0) / (255,255,255).

Repair it, then call qr.show(result) to draw the QR you can scan. An (n, n, 3) array is drawn exactly as RGB; a 2D array also works (a 0/1 mask or a 0–255 grayscale image).

qr.seen is a list of every previous broken QR (oldest first); qr.seen[0] is the very first code you saw — a handy reference.

Ctrl/Cmd+Enter or Ctrl/Cmd+S runs your code.
